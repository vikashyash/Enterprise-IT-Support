# Phishing and suspicious email

## How to recognise a bad message

- The sender looks like IT or HR but the address is not `@aethertech.example`
- A link asks you to "re-authenticate" and the page is not `login.microsoftonline.com`
- Urgent language about payroll, visa, or mailbox deletion
- An attachment named `invoice.iso`, `resume.exe`, or a macro-enabled Excel file you did not expect

## What to do

1. Do not click the link and do not enable macros.
2. In Outlook, click **Report → Report phishing**. That sends a copy to Security and removes it from your inbox.
3. If you already clicked and typed a password, change the password through official self-service and tell the support agent immediately.

## What IT will never send

IT will never mail you a VPN password, a shared OneDrive of "all-staff W-2 forms", or a request to install AnyConnect from a Dropbox link. Those are phishing even if they use a manager's display name.

## After you report

You do not need a ticket for a message you only reported. You do need a security conversation if you entered credentials or downloaded a file.
